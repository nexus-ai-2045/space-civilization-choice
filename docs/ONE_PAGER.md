# 一枚設計：宇宙文明の選択権

## 問い

> 2026年の日本の技術投資は、将来の宇宙社会で日本を「利用者」「不可欠な協力者」
> 「ルール形成者」「独自文明へ進める種を持つ社会」のどこへ導くか。

月面文明の完成を予定されたゴールにしない。月は最初の検証領域であり、観測対象は、
日本が宇宙で自らの技術、制度、文化、対外関係を選べる能力を残せるかである。

## スタート：2026年の現実

- 日本は米国主導のアルテミス計画に参加している。
- JAXAは有人与圧ローバーを開発し、10年間運用する役割を担う。日米間の取決めでは、
  日本人宇宙飛行士2名の月面活動機会も示されている。
- 宇宙戦略基金は、企業・大学等による技術開発を最大10年間支援する。
- 月極域への高精度着陸では、日本の月面輸送能力・機会の自立性と国際競争力が政策目的に含まれる。
- 恒久的な日本の月面居住社会はまだ存在しない。未来の居住者や国家を初期エージェントに置かない。

## 一つの事件：2026年の追加重点枠

> 予算、人材、重要部品の制約により、日本は月面技術の追加重点枠を、今後10年間、
> 一つの技術ツリーへ集中させなければならなくなる。

これは実在する政府決定の記述ではなく、現実の政策・事業を入力にした**シナリオ仮説**である。

| 技術ツリー | 優先するもの | 初期の利点 | 長期リスク |
|---|---|---|---|
| 国際統合型 | アルテミス互換、有人与圧ローバー、国際分業 | 月面活動機会と国際的信頼 | 重要機能を外部標準へ固定する可能性 |
| 国内自立型 | 国産着陸・輸送・通信・重要部品 | 自立性と国内産業基盤 | コスト集中と孤立、重複開発 |
| 開放基盤型 | 公開インターフェース、共有データ、大学・中小企業の参加 | 参入者と応用の多様性 | 投資回収、責任分界、統合統治の難しさ |

## エージェント

MVPでは粒度を「意思決定する組織」に揃える。

1. 日本の政策・資金配分主体
2. 大型探査プロジェクトを担う国内連合
3. 月面輸送・部品を担う新興企業連合
4. 大学・研究機関・次世代技術者の連合
5. アルテミスの国際協力パートナー群

固有組織の実際の意図を推測せず、公開された制度上の役割とシナリオ内の選好を分ける。

## 異なる二領域と一本の因果連鎖

選ぶ二領域は、**地球上の公的資金・知財・人材育成**と、
**宇宙の技術基盤・標準・将来社会の自己決定**である。

```text
2026年の追加重点枠（経済・組織）
  → 生き残る技術・企業・技能の偏り（物理・物質／経済・産業）
  → インターフェース・知財・供給網への固定（経済・産業・組織）
  → 「日本は宇宙で何者か」という役割認識（認知・文化・意味）
  → 月・軌道上で採用される参加条件と統治規範
  → 将来の宇宙社会が日本のアクセス・同盟・産業を決め返す（因果の帰還）
```

通常の宇宙安全保障が現在の衛星・通信・輸送を守るのに対し、本作は、現在の非軍事的な
資金配分、知財、人材の選択が、将来「誰が宇宙秩序を選べるか」を作り、その秩序が日本の
安全保障へ戻る循環を扱う。

## シミュレーションとゴール

同じ2026年のスナップショットとseedから三つの技術ツリーを分岐させ、
`2026 → 2030 → 2035 → 2040` の4ラウンドを比較する。

| 観測軸 | 問い |
|---|---|
| 到達・運用 | 日本主体で必要な輸送・運用を継続できるか |
| 産業再生産 | 重要部品、ソフトウェア、技能を国内・協力圏で再生産できるか |
| ルール形成 | 標準、データ利用、参加条件の決定に関与できるか |
| 知識継承 | 次世代の技術者と組織へ知識を移せるか |
| 関係選択 | 一つの国家・企業へ固定されず協力関係を選べるか |
| 公的正統性 | 地球社会が長期投資の意味と負担を受け入れるか |

2040年の状態を `従属的な利用国`、`不可欠な協力国`、`宇宙秩序のルール形成国`、
`独自文明へ進める種を持つ社会` として記録する。これは優劣の事前設定ではなく、
どの連鎖がどの状態を生んだかをturn ID付きで説明するための観測ラベルである。
