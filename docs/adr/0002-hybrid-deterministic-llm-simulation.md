# ADR-0002: 決定論的コアと限定LLMを分離する

- 状態: accepted
- 日付: 2026-08-24

## 文脈

LLMだけで長期simulationを進めると、同一条件の再現、因果追跡、数値制約、事実と創作の分離が
難しい。一方、固定規則だけでは交渉や役割認識など意味層の候補が単純化される。

## 決定

状態遷移、制約、seed、event logは決定論的コアが所有する。LLMはMVP後のopt-in機能として、
交渉案、行動理由、意味層の解釈候補を構造化出力で提案する。許可行動、schema、予算を検証し、
コアだけが状態へ適用する。最初のLLM実装は単一エージェントとする。

## 結果

LLMなしのreplayが可能になり、LLMの失敗を棄却として記録できる。代わりに、adapterと検証器、
prompt版管理、評価caseが必要になる。

## 見直し条件

固定規則では意味層の比較が成立しないことをユーザーテストで確認したとき、または複数agentの
相互作用が単一agentより再現性・説明性を改善するとevalで示せたとき。
