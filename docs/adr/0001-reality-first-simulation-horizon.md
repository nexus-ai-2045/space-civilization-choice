# ADR-0001: 2026年の現実を起点にする

- 状態: accepted
- 日付: 2026-08-24

## 文脈

未来の月面居住圏を初期状態にすると、登場主体も制度も仮構になり、何を検証しているかが曖昧になる。
一方、月面文明を必達ゴールにすると、結末を先に決めた物語になる。

## 決定

開始点は2026年の日本の公開政策、技術開発、組織上の役割とする。一つの追加重点枠だけを
シナリオ仮説として加える。終了点は2040年の月面文明完成ではなく、日本が宇宙で技術、制度、
文化、対外関係を選べる能力をどこまで保持したかの観測とする。

## 結果

現実との接点と反証可能性が増す一方、未来社会の派手な描写は主役にならない。2040年の状態は
予測ではなく、仮定に依存する比較結果として扱う。

## 見直し条件

公的な新制度、実証済みの月面活動、基準年の変更がMVP入力へ影響するとき。
