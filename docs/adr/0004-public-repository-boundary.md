# ADR-0004: 公開repoと内部資料を分離する

- 状態: accepted
- 日付: 2026-08-24

## 文脈

設計の出発点には会話、応募情報、非公開資料が含まれ得る。公開repoへ混ぜると、個人情報、権利、
更新可能性、出典の正確性を管理できない。

## 決定

公開repoにはrepo独自文書、コード、synthetic fixture、公式公開URLと必要最小限の要約だけを置く。
応募情報、メールアドレス、参加者番号、内部資料、第三者文書本体、private logは収録しない。
ローカルの`private/`はignoredであり、公開設計の正本にしない。

## 結果

公開面は第三者が単独で読める一方、内部の議論や応募receiptは別に管理する。公開前にはsecret、
personal path、tracked-and-ignored、history、licenseを再検査し、人間レビューを必須にする。

## 見直し条件

第三者資料を再配布する明示的な権利を得た場合でも、追加前に新しいADRと公開レビューを行う。
