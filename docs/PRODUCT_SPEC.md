# プロダクト仕様

## 誰の、どんな判断を助けるか

主な利用者は、ハッカソン審査者、政策研究者、宇宙産業の実務者、技術政策を学ぶ市民である。
利用者が行う仕事は、同じ2026年の条件から三つの介入を比較し、短期の成功と長期の選択肢が
一致しない場面を発見し、その理由を証拠とturn IDで説明することにある。

## 中核体験

1. 2026年の公開事実とシナリオ仮説を確認する。
2. 追加重点枠を三つの技術ツリーの一つへ配分する。
3. 組織エージェントが各ラウンドで投資、協力、標準化、人材育成を選ぶ。
4. 状態遷移を確定し、モデル内部遷移イベントを台帳へ記録する。
5. 同じseedで別の技術ツリーへ分岐し、2040年の差を比較する。
6. 「勝者」ではなく、得た能力、失った選択肢、未知の前提を持ち帰る。

## ハッカソンMVP要件 v2

### 中心となる問い

日本社会が宇宙進出へ与える意味、期待、不安は、予算、人材、企業投資、国際協力をどう動かし、
2040年に日本が宇宙で保持する選択権をどう変えるか。さらに、宇宙での成功、依存、事故は、
日本社会の認識と支持へどう戻るか。

このプロダクトは2040年を予言するものではない。利用者が介入条件を変更し、どの連鎖が増幅し、
どこで脆弱性または選択肢喪失が生じるかを比較する探索用シミュレーターである。

### 二つの出発領域と一本の連鎖

- 出発領域A: **宇宙**。輸送、運用、生命維持、通信、エネルギー、現地生産、資源、規範。
- 出発領域B: **認知・文化**。期待、恐怖、信頼、国家威信、公平感、未来世代への責任、若者の関心。
- 伝達経路: **経済・組織**。国家予算、民間投資、企業、大学、人材、供給網、知財、標準、国際協力。

観測対象は個別領域の点数ではなく、次の循環である。

```text
意味・期待・不安
→ 国民支持・人材選択
→ 予算・企業投資・国際協力
→ 技術・供給網・宇宙運用能力
→ 成功・依存・事故・規範形成
→ 社会の意味・期待・不安へ戻る
```

### 利用者が操作するもの

利用者は「国際統合型」などの抽象的な方針名を直接選ばない。総資源を、輸送、自律運用、
生命維持、エネルギー、国内供給網、人材・研究、国際接続、開放基盤へ配分する。さらに国内調達率、
技術公開度、国際依存許容度、短期成果志向、リスク許容度を調整する。三つの従来方針は、具体的な
初期値を持つ比較用presetとして残す。

### 操作レベル

1. **簡単設定**: 総予算、国内自立、国際協力、長期志向、社会支持の主要5項目。
2. **詳細設定**: 投資、依存、技術、人材、認知、外部環境を合わせた約20項目。
3. **実験設定**: 各parameterの範囲とrun budgetを指定し、複数seedを自動比較する。

### AIエージェントの最低要件

- 政策配分主体、国内探査連合、輸送・部品企業、大学・次世代人材、国際協力主体を分離する。
- 各主体は役割、観測可能情報、選好、資源制約、許可行動を持つ。
- 各ラウンドで提案、交渉、採択または棄却を行い、認識と行動を更新する。
- LLMは意味、交渉、理由を提案するが、状態値を直接変更しない。
- 決定論コアだけが検証済みactionを状態遷移へ変換する。
- LLM停止時も同じ入力からfallbackで完走し、AI利用の有無を結果に表示する。

### 画面で説明できなければならないこと

- 利用者が何を変更したか
- 各主体が何を認識し、何を提案し、何が採択されたか
- どのparameterと外部eventが各状態差分へ影響したか
- 物理・物質、経済・組織、認知・文化のどこを連鎖が通ったか
- 得た能力、増えた依存、失った選択肢、残る未知
- 同一条件の再実行hashと、別条件との差

### ハッカソン評価への接続

- **創発性**: 複数主体の局所判断から、事前に固定していない協力、対立、依存が生じる。
- **連鎖の説得力**: 宇宙と認知・文化の間を、経済・組織の状態遷移で接続する。
- **介入点**: parameter変更によって連鎖が変わる閾値を比較できる。
- **実装品質**: schema、allowlist、replay、trace、fallback、hashで検証する。
- **社会実装**: 政策対話、研究、教育、組織戦略の仮説比較へ利用できる。
- **拡張性**: model cardとparameter registryから領域、主体、規則を追加できる。

三分岐は、利用者が最初に一つを選んだ後、同じsnapshot、seed、model version、外生event列から
残り二つも反実仮想として並列実行する。各branchで変更できるのは、選んだ技術ツリーと、そこから
モデル規則から生じる行動・状態だけである。これは実世界の因果推定を意味しない。

## プレイヤーが行う動詞

- 配分する
- 交渉する
- 標準を選ぶ
- 能力を育てる
- 分岐する
- 比較する
- モデル内因果をたどる
- 仮定を反証する

## セッション

1セッションは、初期条件の確認、4ラウンドの実行、三分岐の比較、振り返りで15〜25分を想定する。
失敗はゲームオーバーではない。供給網の不可逆な固定、技能継承の断絶、公的正統性の喪失、
選択肢の縮小が、説明可能な失敗状態になる。

## 成功条件

- 三分岐が同一snapshotとseedから再生できる
- 各指標の変化が最低一つの入力、行動、状態遷移へ遡れる
- 知識状態、生成元、検証状態を直交するfieldとして画面上で区別できる
- 結果の差より先に、モデル内因果の差を説明できる
- 「月面文明が完成した」という未根拠の結末を自動生成しない
- ゴール契約の各done_when IDが、test、run manifest、または人間レビュー記録へ結び付く
- review時点で現在状態を更新しても、旧runを上書きせず比較と再現ができる

## 非目標

- 日本政府や企業の実際の意思決定を再現すること
- 軍事作戦、攻撃、情報工作を最適化すること
- 2040年を予言すること
- 文明や国家を一つの総合点で序列化すること
- LLMの雄弁さをシミュレーション精度とみなすこと
