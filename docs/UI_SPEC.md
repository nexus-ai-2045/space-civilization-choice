# UI仕様

Figmaへ移せる情報設計を先に定義する。外部Figmaファイルや画像コンセプトはまだ作成していない。
実装前に3案の視覚コンセプトを比較し、人間が一案を選ぶ。

## 体験の署名

一般的なKPIダッシュボードではなく、三層を横切る一本の「モデル内因果軌道」を主役にする。各turnは
地球側の判断から宇宙側の条件へ飛ぶ軌道点として描き、選択肢が増えた箇所と失われた箇所を
線種とラベルで示す。装飾的な宇宙背景や巨大なheroは使わない。

## 画面

### 1. シナリオ設定

- 2026年snapshot、事実、仮説、未知を別領域で確認
- 三つの技術ツリーから一つを選択
- seedとモデル版を表示
- 「比較実行」を一つの主要操作にする

### 2. 分岐比較

- 三分岐を同じ時間軸へ整列
- 六観測軸を同一scaleのsmall multiplesで同時表示
- 総合点や勝者badgeを置かない
- 重要な差からモデル内因果トレースへ移動

### 3. モデル内因果トレース

- 物理・物質、経済・産業・組織、認知・文化・意味の三lane
- 一つの時間軸上にturnを配置
- 選択した差分について、前状態、行動、規則、後状態を表示
- 反実仮想の同turnへ移動できる

### 4. 証拠台帳

- `record_kind`、`epistemic_class`、`provenance_type`、`validation_state`を別のlabelとして表示し、
  LLM由来と未知、提案の棄却と仮説の反証を混同しない
- 出典、確認日、該当主張、反証条件を表示
- 外部リンクは新しい情報として扱い、状態へ自動反映しない

## デザイントークン案

4〜6色に限定し、色だけで意味を伝えない。

| token | 用途 |
|---|---|
| `ink` | 本文、軸、主要ラベル |
| `paper` | 背景 |
| `orbit` | 選択中の因果軌道 |
| `earth` | 地球側の状態 |
| `moon` | 宇宙側の状態 |
| `warning` | 未知、棄却、選択肢喪失 |

数値はtabular figuresを使う。本文と証拠は可読性の高い日本語sans、turn IDとseedはmonoを使う。
最終fontは実装環境の配布条件を確認して決める。

## コンポーネント状態

技術ツリー選択、因果ノード、証拠チップ、分岐lane、turn詳細、実行確認、エラー、空状態を定義する。
hoverだけに情報を置かず、focus、selected、disabled、loading、errorを明示する。

## アクセシビリティ

- 320pxからdesktopまで、横スクロールを前提にしない
- keyboardだけで分岐、turn、証拠へ移動できる
- 動的結果は`aria-live="polite"`、検証エラーは`role="alert"`を使う
- 色と同時に形、線種、文言を使う
- animationは状態間の移動に限定し、`prefers-reduced-motion`で停止する
- chartには軸名、単位、読み上げ用要約を付ける
